# Simple Arabic Speaking Practice Website

## What is it?
One single webpage for Arabic students to practice speaking.

## User Experience (Step by Step)
1. User opens the website 
2. User sees Arabic text on screen
3. User clicks play button to hear correct pronunciation
4. User clicks record button and reads the Arabic text
5. User stops recording
6. Speechmatics converts their speech to text
7. User sees their transcription compared to the original text
8. User can try again or move to next exercise

## What's on the page?
- Arabic text to read
- Play button for correct audio
- Record button for user's voice
- Area showing user's transcription
- Simple comparison of what they said vs target text

## Technical Setup
- One HTML page only
- No database needed
- Speechmatics API for Arabic speech-to-text
- Browser microphone for recording
- Hard-coded exercises in the page

That's it. One page, Speechmatics, done.
